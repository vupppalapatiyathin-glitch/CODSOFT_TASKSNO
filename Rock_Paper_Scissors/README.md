# Rock Paper Scissors Game

## Description
This is a simple Rock, Paper, Scissors game developed using Python. The user plays against the computer, which randomly selects Rock, Paper, or Scissors. The game keeps track of the score and allows the user to play multiple rounds.

## Features
- User vs Computer gameplay
- Random computer choice
- Score tracking
- Input validation
- Play multiple rounds

## Technologies Used
- Python
- Random module

## How to Run
1. Download the project.
2. Open the Python file in any Python IDE or VS Code.
3. Run the program.
4. Enter rock, paper, or scissors when prompted.
